# CodeAlpha_Music_player
Music Player Project
This is a simple and responsive Music Player built using HTML, CSS, and JavaScript. The project focuses on providing a clean and modern user interface along with essential music controls.

Features
Cover Images: Displays the cover art for each track, enhancing the visual experience.

Play / Pause Button: Allows users to easily play and pause the current track.

Next / Previous Buttons: Navigate through the playlist with simple controls.

Hover Effects: Smooth hover animations applied to buttons and images for a more interactive feel.

Responsive Design: The music player layout adjusts seamlessly across various screen sizes, making it accessible on desktops, tablets, and mobile devices.

Technologies Used
HTML: For structuring the player layout and elements.

CSS: For styling, animations, hover effects, and responsive design.

JavaScript: For handling music controls, track changes, and dynamic content updates
